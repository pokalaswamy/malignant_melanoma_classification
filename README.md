 Malignant Melanoma Classification Using Deep Learning and Explainable AI 
 Description - Deep learning based skin lesion classification using the ISIC 2019 dataset. - Classifies 9 skin lesion classes using a CNN model. - Achieves around 83.75% test accuracy. - Explainability provided via Grad-CAM, LIME, and SHAP. 
  Tech Stack - Python - TensorFlow Keras - Flask backend. 
  Dataset - ISIC 2019 from Kaggle. - Resized and augmented. 
  How to Run 1. Install requirements. 2. Start the backend server. 3. Run the application.
